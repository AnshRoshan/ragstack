RAGStack is a Python package that indexes your documents four ways at once — keyword, vector, knowledge-graph and SQL — then lets an AI agent route each question across them, multi-hop, with citations.

The core idea

No single search wins everywhere.

Exact error codes defeat embeddings. Vague questions defeat keywords. Relationship questions defeat both. RAGStack runs all of them side by side — and fuses the results when it helps.

Agentic RAG

A researcher, not a search box.

For complex questions, a single lookup isn't enough. RAGStack's agent reasons in a loop — picking tools, reading results, judging evidence quality, and chaining hops until it can actually answer.

  • 1Plans per question

    Compound asks get decomposed into sub-queries searched in parallel; simple ones skip the ceremony.

  • 2Picks tools per hop

    Nine tools across all four paradigms — the output of one hop becomes the query of the next.

  • 3Grades its own evidence

    A CRAG-style check rates every retrieval. Irrelevant results trigger a strategy change, not a confident guess.

  • 4Stops honestly

    A hard step budget ends loops; on the final step the agent must answer from what it found — or say what's missing.

Your call, always

Eight retrieval modes. You choose the trade-off.

Full agency when the question deserves it; fast single-pass pipelines when it doesn't. Every mode streams progress and returns cited answers.

Quickstart

From zero to answers in three commands.

 terminal
# install
pip install ragstack

# index a folder of documents
ragstack index ./docs

# ask — or run `ragstack serve` for the web UI
ragstack query "how does fusion rank results?"
 python
from ragstack import RAGStack

svc = RAGStack("ragstack.yaml")
svc.ingest(["./docs"])

answer = svc.query(
    "which components depend on the auth service?",
    mode="agentic",   # or vector | lexical | hybrid |
                       #      graph | global | sql | auto
)
print(answer.text)
