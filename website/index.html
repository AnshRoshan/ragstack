§01 · PARADIGMS

Exact error codes defeat embeddings. Vague questions defeat keywords. Relationship questions defeat both. RAGStack runs all four side by side, and fuses the results when it helps.

Keyword · vectorless

Classic BM25 over whole pages and chunks. Ranking comes straight from word statistics; nothing drifts.

+ exact names, IDs, error codes
− misses paraphrased meaning
tantivy
Vector · meaning-based

Chunks become embedding vectors, so questions find answers even when the words don't match the documents.

+ concepts, synonyms, fuzzy intent
− weak on exact identifiers
LanceDB + BGE
Knowledge graph

Entities and relations extracted from your corpus form a graph. Walk connections for multi-hop questions; summarize clusters for corpus-wide themes.

+ who-connects-to-what, themes
− needs LLM extraction at index time
SQLite · Neo4j optional
Your SQL databases

Register any database and the agent writes read-only SELECT queries against introspected schemas for numbers and records.

+ aggregates, records, joins
− structured data only

§02 · AGENT

For complex questions a single lookup isn't enough. The agent reasons in a loop: picking tools, reading results, judging evidence quality, chaining hops until it can actually answer.

  • 1Plans per question

    Compound asks get decomposed into sub-queries searched in parallel; simple ones skip the ceremony.

  • 2Picks tools per hop

    Nine tools across all four paradigms; the output of one hop becomes the query of the next.

  • 3Grades its own evidence

    A CRAG-style check rates every retrieval. Irrelevant results trigger a strategy change, not a confident guess.

  • 4Stops honestly

    A hard step budget ends loops; on the final step the agent must answer from what it found, or say what's missing.

Eight retrieval modes.
You choose the trade-off.

§05 · FEATURES
Citations on every claim[S1]-style markers resolve to exact sources, tracked across every hop.
Semantic response cacheNear-duplicate questions answered instantly; stricter threshold when queries sound uncertain.
Query decomposition"Compare X and Y" becomes parallel sub-searches fused into one ranked list.
Docling ingestionPDF, Word, PowerPoint, Excel and scanned images. Layout-aware, OCR included.
Local-first privacyEverything runs on your machine unless you explicitly configure a cloud provider.
Three stack modesFully local (Ollama), hybrid, or full cloud; one config line switches between them.
Streaming everythingSSE events for thoughts, tool calls and answers power CLI and web UI alike.
Built-in evaluationGolden-set harness reports hit-rate, MRR and LLM-judged faithfulness.
Claim-level verificationEvery answer is split into atomic claims, checked against its citations, and withheld if support falls below threshold.
Audit tracesEvery query writes a replayable trace: routes taken, tools called, evidence used, verification results.
Injection defenseRetrieved content is treated as data, never instructions; sources cannot hijack the agent.
Adaptive routingA classifier picks no-retrieval, clarification, structured query, fast pipeline or agentic research per question.

§07 · QUICKSTART
 terminal
# install
pip install ragstack

# index a folder of documents
ragstack index ./docs

# ask (or run `ragstack serve` for the web UI)
ragstack query "how does fusion rank results?"
 python
from ragstack import RAGStack

svc = RAGStack("ragstack.yaml")
svc.ingest(["./docs"])

answer = svc.query(
    "which components depend on the auth service?",
    mode="agentic",   # or vector | lexical | hybrid |
                       #      graph | global | sql | auto
)
print(answer.text)
