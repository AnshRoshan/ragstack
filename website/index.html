RAGStack indexes your documents four ways at once — keyword, vector, knowledge-graph and SQL — then routes every question through whichever strategy suffices. Every answer is split into claims, checked against its citations, and withheld when support is thin.

§QS
 terminal
# install
pip install ragstack

# index a folder of documents
ragstack index ./docs

# ask — or `ragstack serve` for the console
ragstack query "how does fusion rank results?"
 python
from ragstack import RAGStack

svc = RAGStack("ragstack.yaml")
svc.ingest(["./docs"])

answer = svc.query(
    "which components depend on auth?",
    mode="agentic", session_id="team",
)
print(answer.text)
print(answer.confidence)
